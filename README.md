# Бот: ники → Google-таблицы по учебным заведениям

- У каждого человека (например, **Умид**) своя Google-таблица.
- В таблице отдельный **лист на каждое учебное заведение (УЗ)**. Листы создаются автоматически.
- У каждого УЗ своя ссылка: `https://t.me/<бот>?start=umid__school1`.
- Когда пользователь переходит по ссылке, его **ник сразу записывается** в лист этого УЗ, ещё до того, как он поделится номером.
- Когда пользователь делится номером, номер дописывается в ту же строку.

Колонки листа: `Дата перехода | Telegram ID | Ник | Имя | Телефон | Дата номера`.
Если человек перейдёт по ссылке повторно, строка обновится, а не задублируется.

## Настройка

1. **Google-аккаунт сервиса.** В Google Cloud Console включите *Google Sheets API*,
   создайте Service Account, скачайте JSON-ключ и положите его рядом с ботом как `credentials.json`.
2. **Таблицы.** Создайте по одной пустой Google-таблице на каждого человека
   (например, «Таблица Умида») и откройте к ней доступ **редактора** для email
   сервисного аккаунта (`...@...iam.gserviceaccount.com`).
   ID таблицы — это часть ссылки между `/d/` и `/edit`.
3. **Конфиг.** Скопируйте `config.example.json` в `config.json` и заполните:
   ```json
   "umid": {
     "title": "Умид",
     "spreadsheet_id": "1AbC...xyz",
     "institutions": { "school1": "Школа №1", "lyceum5": "Лицей №5" }
   }
   ```
   Ключи (`umid`, `school1`) пишите латиницей, цифрами, `_` или `-` (без `__`).
   Название справа будет названием листа.
4. **Запуск.**
   ```bash
   pip install -r requirements.txt
   export BOT_TOKEN=123:ABC          # токен от @BotFather
   export ADMIN_IDS=111111111        # ваш Telegram ID (через запятую, если несколько)
   python bot.py
   ```
5. **Ссылки.** Напишите боту `/links`, и он пришлёт ссылки на все УЗ, сгруппированные по людям.

Необязательные переменные: `CONFIG_PATH`, `GOOGLE_CREDENTIALS`, `STATE_PATH`,
`TIMEZONE` (по умолчанию `Asia/Tashkent`).

Чтобы добавить человека или УЗ, допишите их в `config.json` и перезапустите бота.
Новые листы появятся сами.
